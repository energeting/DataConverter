# DataConverter — учебный проект для лабораторной по CI/CD

DataConverter — консольная утилита на C++17 для преобразования табличных данных между CSV, JSON и YAML.

## Локальная сборка и тесты

Зависимости `yaml-cpp` и GoogleTest автоматически скачиваются CMake через
`FetchContent`. Нужны CMake 3.20+, компилятор с поддержкой C++17 и доступ к
GitHub при первой конфигурации.

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DDATACONV_BUILD_TESTS=ON
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

## CI

Workflow [`.github/workflows/ci.yml`](.github/workflows/ci.yml) запускается на
`push` и `pull_request`, затрагивающих исходный код, тесты, CMake-конфигурацию
или сам workflow. Он выполняет матрицу `ubuntu-latest`, `macos-latest` и
`windows-latest`.

Задание `test` зависит от `build` через `needs: build`: оно получает дерево
сборки из артефакта, запускает CTest и публикует JUnit-отчёт. Кэшируется
`build/_deps` — исходники и служебные данные зависимостей, полученные CMake.
Ключ включает ОС и хеш `CMakeLists.txt`; поэтому зависимости не смешиваются
между платформами и кэш обновляется при изменении их описания.

### Эксперимент с `fail-fast`

В штатной конфигурации указано `fail-fast: false`: ошибка в одном варианте
матрицы не отменяет оставшиеся варианты. Для эксперимента временно внесите
ошибку в проверку из `tests/converter_tests.cpp`, отправьте commit и посмотрите
статусы всех шести задач. Затем замените оба значения на `fail-fast: true` и
повторите: невыполненные задачи той же матрицы могут быть отменены после первой
ошибки. Верните тест и `fail-fast: false` до сдачи.

### Кэш и артефакты

Первый запуск создаёт кэш зависимостей; повторный запуск без изменения
`CMakeLists.txt` обычно не скачивает их заново. Изменение исходника не меняет
ключ зависимостей и само по себе не обязано давать заметное ускорение: основное
время может занять компиляция. Артефакты — это результаты конкретного запуска
(отчёты `test-results-*`, а также собранная утилита `dataconv-*`), которые можно
скачать из интерфейса Actions. Кэш предназначен для повторного использования в
будущих запусках и может быть вытеснен; артефакт — для просмотра или передачи
результата данного запуска.

Успех на одной ОС не доказывает успех на других: отличаются компиляторы,
стандартные библиотеки, пути, регистр файловой системы, линковка и доступные
системные API.
